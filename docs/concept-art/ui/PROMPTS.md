# Issekaied UI visual concepts

These four screens are design mockups generated with the native built-in image_gen tool, not running-game screenshots. All calls requested transparent_background=false. The selected PNGs were copied unchanged; original generated files remain in the Codex generated_images directory.

Each prompt below is the exact string passed to the image tool.

Premium quiet menace, elegant spacing, sharp readable controls, subtle fine-line brass rules and borders. No excessive ornament, neon gradients, purple glow, glossy dashboard cards, clutter, or stock fantasy UI. Warm title lettering against dark blue, excellent contrast at normal desktop size.
