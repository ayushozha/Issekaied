# Issekaied project pitch

Horror encounters can become predictable when enemies repeat the same tricks. Issekaied makes Halloween personal: ghosts remember who defeated them, share warnings, and return with new grudges. Divine incantations, eerie voices, and a haunted adventure make every hunt spooky, surprising, and fun.

Character count: 297 (limit500).
