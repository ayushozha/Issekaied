# Issekaied generated character assets

Created with the native built-in image_gen tool. The four power portraits requested transparent backgrounds; the enemy sheet requested an opaque dark studio background. Original generated files remain in the Codex generated_images directory; the selected PNGs were copied here without image editing.

Each prompt below is the exact string passed to image_gen.
